INVIT

투자 정보를 추천하는 서비스가 아니라, 사용자가 자신의 편향·충동·규율을 기록하고 돌아볼 수 있도록 설계한 Investment Behavior Correction OS입니다.

Assessment · Journal · Principles · AI Coaching
중요 제한
투자 추천·자문 제품으로 소개하지 않음

프로젝트 한눈에 보기

  • 문제: 투자 과정의 실수는 정보 부족뿐 아니라 자신의 편향과 행동 패턴을 돌아보지 못하는 데서 생길 수 있습니다.
  • 접근: 진단, 기록, 원칙, 규율 점검, AI coaching을 자기관찰의 흐름으로 연결합니다.
  • 형태: 모바일 사용 흐름을 중심으로 설계합니다.
  • 경계: 특정 종목·매수/매도·수익을 추천하거나 투자자문을 제공하는 제품으로 설명하지 않습니다.

무엇을 해결하려는가

투자 관련 서비스는 더 많은 정보, 더 빠른 시세, 더 정확한 예측에 집중하기 쉽습니다. INVIT는 다른 문제를 봅니다. 사용자가 어떤 상황에서 충동적으로 행동하고, 자신의 원칙을 얼마나 지키며, 같은 실수를 반복하는지를 스스로 기록하고 점검하는 흐름입니다.

따라서 제품의 중심은 “무엇을 사야 하는가”가 아니라 “나는 어떤 기준으로 판단했고 그 기준을 지켰는가”에 있습니다.

제품 범위와 공개 역할

현재 공개 범위는 Bias Assessment, Journal, Discipline Score, Principles, AI Coaching입니다. 구현과 Release Gate가 계속 진행 중이므로 실제 출시 완료나 사용자 성과를 전제하지 않습니다. 기술 범주는 React Native, Expo, Supabase, Auth, Postgres, RLS, Edge Functions, RevenueCat, Push를 포함합니다.

행동 코칭 흐름

ASSESS자신의 편향과 행동 경향을 돌아봅니다.
RECORD판단과 행동의 맥락을 Journal에 남깁니다.
CHECK세운 원칙과 규율을 얼마나 지켰는지 점검합니다.
REFLECTAI coaching은 추천보다 자기점검을 돕는 방향으로 둡니다.

핵심 제품 판단

예측보다 자기관찰

제품의 가치 제안을 수익 예측이나 종목 추천으로 옮기지 않고 사용자의 행동 기록과 규율 점검에 둡니다.

AI는 결정권자가 아니다

AI coaching이 있더라도 사용자의 투자 결정을 대신하거나 개인화된 금융자문을 제공하는 것으로 표현하지 않습니다.

모바일 반복 사용

진단 한 번보다 실제 판단 시점 전후에 기록하고 돌아볼 수 있는 반복 흐름을 중요하게 봅니다.

Release Gate 분리

소스 구현, 구독, Push, 배포 같은 운영 상태는 별도 검증 대상이며 포트폴리오 문구에서 완료를 선반영하지 않습니다.

현재 상태

`IN BUILD / RELEASE-GATED`는 제품이 구축 중이며 출시 관련 검증을 통과해야 하는 상태라는 뜻입니다. 이 문서는 출시 완료, 구독 활성화, 실사용자 수, 투자성과를 주장하지 않습니다.

재사용 가능한 제품 설계 원칙

  • 규제·신뢰가 중요한 제품은 “무엇을 하지 않는가”를 value proposition과 함께 명확히 합니다.
  • AI가 제공하는 설명과 사용자의 최종 판단 책임을 구분합니다.
  • 한 번의 진단보다 반복 행동을 기록할 loop를 설계합니다.
  • 제품 marketing copy가 기능 범위를 넘어 금융자문처럼 읽히지 않는지 검토합니다.
  • Release, Billing, Push 같은 운영 준비 상태를 별도 Gate로 관리합니다.
