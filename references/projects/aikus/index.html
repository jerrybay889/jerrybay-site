AIKUS

AI를 배우는 데서 끝내지 않고 실제 업무 결과로 연결하기 위한 Learning + Work Execution System입니다. Learning Lab과 Work Studio를 하나의 사용 흐름으로 설계·구축하고 있습니다.

Project Overview

학습과 실행이 분리되지 않도록 설계합니다.

콘텐츠를 소비하는 학습 화면과 실제 업무를 수행하는 작업 화면을 연결하고, 개인별 아카이브와 구독 흐름까지 하나의 제품 구조 안에서 다룹니다.
