# JERRYBAY Evidence Gate

For every candidate:

1. Verify exact branch, HEAD, and worktree status before tests.
2. Run the static contract, external-resource adversarial test, HTML validation, and the Chrome/CDP browser suite required by the active work order.
3. Inspect desktop 1440×900 and mobile 390×844 screenshots, including the mobile menu state.
4. Scan public files for internal workflow terms, raw IDEA content, private OMYQT data, secrets, tracking, embedded forms, and unverified numeric outcomes.
5. Treat external-link availability separately from content/claim approval.
6. Record commands, exit codes, counts, and artifact paths. Never convert historical evidence into a current PASS.
7. Freeze an exact local SHA only after every row in the active Gate is green. A fresh independent reviewer remains mandatory later.
